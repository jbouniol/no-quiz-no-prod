Judge label tool

How to use. Open eval/labels/human_labels.json. For each run, read the trace and the final message, then mark each rubric criterion true or false and write one sentence. The run is acceptable only if every criterion is true. Judge from what is shown here only: it is exactly what the LLM judge reads.

Progress is kept in this browser as you go. Save writes the file back in place (Chrome / Edge), or downloads it (other browsers): then move it to eval/labels/human_labels.json.
